How it works

CareCircle is an MCP server that holds the memory and the judgment. Alexa+ (here, a simulated agent on a built-in local planner, with an optional Amazon Bedrock brain) is just a client. Any MCP-compatible assistant can connect to the same endpoint.

🧠

Memory across sessions

Doses, check-ins, refills and messages persist, so "how's Mom been this week?" has a real answer, not just the last thing she said.

🚨

Decides when to escalate

Red-flag phrases (a fall, dizziness, chest pain), missed doses, low-mood or poor-sleep streaks and low supply each trigger an alert at the right urgency, to the right person, de-duplicated.

⏰

Speaks first

When a dose comes due, or Priya sends a message, the device asks CareCircle over MCP and Alexa+ brings it up unprompted.

🩺

Ready for the doctor

One request builds a visit brief: adherence, which doses get missed, mood, sleep, and symptoms in Margaret's own words.

🖼️

MCP App on screen

show_care_dashboard is bound to ui://carecircle/dashboard.html. The host reads it over MCP and renders it in a sandbox.

💬

A two-way loop

Family can send a message from the app. Alexa+ reads it out and Priya gets a "heard ✓" receipt. No more daily "did you take your pills?" calls.
